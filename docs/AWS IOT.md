# AWS IoT

## Conectando Dispositivos (ESP32) a AWS IoT Core

### Introducción
Guía detallada para conectar dispositivos ESP32 a AWS IoT Core, utilizando certificados y políticas de seguridad para asegurar la comunicación.

### Requisitos Previos
Para seguir esta guía, necesitarás lo siguiente:

*   **Cuenta de AWS:** Acceso a una cuenta de AWS activa y configurada.
*   **AWS CLI:** La interfaz de línea de comandos de AWS, configurada y autenticada con las credenciales adecuadas.
*   **ESP-IDF:** El entorno de desarrollo de Espressif para ESP32, correctamente instalado y configurado.
*   **OpenSSL:** Una herramienta de línea de comandos para generar claves y certificados, necesaria para la seguridad de la comunicación.

### Paso 1: Crear una "Cosa" (Thing) en AWS IoT Core
Una "Cosa" representa tu dispositivo en la nube de AWS IoT.

1.  **Navegar a AWS IoT Core:** Accede a la consola de AWS y busca "IoT Core".
2.  **Gestionar > Cosas:** En el panel de navegación izquierdo, selecciona "Gestionar" y luego "Cosas". Haz clic en "Crear cosas" (o "Register a thing").
3.  **Crear una única cosa:** Selecciona la opción para crear una cosa individual.
4.  **Configurar propiedades de la cosa:**
    *   **Nombre de la cosa:** Asigna un nombre descriptivo (ej. `esp32_device_01`). Este nombre es importante para identificar tu dispositivo.
    *   **Configuración adicional:** Puedes omitir la configuración de tipo de cosa o grupos de cosas por ahora.
5.  **Sin certificado para esta cosa:** En la sección "Configurar certificado", elige la opción "Crear cosa sin generar certificado" (o "No generate a certificate for this thing"). Generaremos los certificados manualmente en el siguiente paso.

### Paso 2: Generar Certificados y Claves de Seguridad
Utilizaremos OpenSSL para generar un par de claves y una solicitud de firma de certificado (CSR) que luego será firmada por AWS.

1.  **Crear un directorio para los certificados:**
    ```bash
    mkdir certs
    cd certs
    ```
2.  **Generar la clave privada del dispositivo:**
    ```bash
    openssl genrsa -out private.pem 2048
    ```
    Este comando crea un archivo `private.pem` que contiene la clave privada de tu dispositivo. **Mantén esta clave segura y nunca la compartas.**
3.  **Generar la solicitud de firma de certificado (CSR):**
    ```bash
    openssl req -new -key private.pem -out csr.pem
    ```
    Se te pedirá que ingreses información. Es crucial que el campo `Common Name (CN)` coincida con el nombre de la "Cosa" que creaste en AWS IoT Core (ej. `esp32_device_01`).
4.  **Generar el certificado del dispositivo (firmado por AWS CA):**
    *   En la consola de AWS IoT Core, ve a **Seguridad > Certificados**.
    *   Haz clic en "Crear certificado" (o "Create certificate").
    *   Selecciona "Cargar certificado generado por CA" (o "Upload a certificate generated by a CA").
    *   Sube el archivo `csr.pem` que generaste.
    *   Después de cargarlo, haz clic en "Activar" para que el certificado esté operativo.
    *   **Descarga el certificado del dispositivo:** Guarda el certificado generado (ej. `device_certificate.pem`).
    *   **Descarga el certificado CA raíz de Amazon:** Es vital descargar y guardar el certificado CA raíz (ej. `AmazonRootCA1.pem`). Este certificado se utiliza para que tu dispositivo confíe en AWS IoT Core.

### Paso 3: Crear y Adjuntar una Política IoT
Las políticas definen qué acciones puede realizar tu dispositivo en AWS IoT Core.

1.  **Navegar a Políticas:** En AWS IoT Core > Seguridad > Políticas.
2.  **Crear política:** Haz clic en "Crear política" (o "Create policy").
3.  **Configurar la política:**
    *   **Nombre:** Dale un nombre significativo a tu política (ej. `esp32_policy`).
    *   **Declaración de política:** Copia y pega el siguiente JSON, asegurándote de reemplazar los marcadores de posición:
        ```json
        {
          "Version": "2012-10-17",
          "Statement": [
            {
              "Effect": "allow",
              "Action": [
                "iot:Publish",   // Permite al dispositivo publicar mensajes
                "iot:Receive",   // Permite al dispositivo recibir mensajes
                "iot:Subscribe", // Permite al dispositivo suscribirse a temas
                "iot:Connect"    // Permite al dispositivo conectarse a AWS IoT Core
              ],
              "Resource": [
                "arn:aws:iot:REGION:ACCOUNT_ID:topic/esp32/data",        // Permite publicar en este tema
                "arn:aws:iot:REGION:ACCOUNT_ID:topicfilter/esp32/data",  // Permite suscribirse a este filtro de tema
                "arn:aws:iot:REGION:ACCOUNT_ID:client/esp32_device_01"   // Permite conectarse con este ID de cliente
              ]
            }
          ]
        }
        ```
        *   Reemplaza `REGION` con la región de AWS donde estás trabajando (ej. `us-east-1`).
        *   Reemplaza `ACCOUNT_ID` con tu ID de cuenta de AWS (lo puedes encontrar en la esquina superior derecha de la consola de AWS).
        *   Ajusta los `topic` y `client` según las necesidades de tu aplicación.
4.  **Adjuntar política:** Una vez creada la política:
    *   En la sección de detalles del certificado que creaste en el **Paso 2**, haz clic en "Acciones" y luego "Adjuntar política". Selecciona `esp32_policy`.
    *   También es buena práctica adjuntar la política a la "Cosa". En los detalles de tu "Cosa", haz clic en "Seguridad", luego "Certificados" y adjunta la política al certificado asociado.

### Paso 4: Configurar el Dispositivo ESP32 (ESP-IDF)
Ahora, integraremos los certificados y la lógica de conexión MQTT en el firmware de tu ESP32.

1.  **Incluir certificados en el proyecto ESP-IDF:**
    *   Copia los archivos `private.pem`, `device_certificate.pem` y `AmazonRootCA1.pem` a un directorio accesible por tu proyecto ESP-IDF, generalmente en el sistema de archivos del dispositivo (ej. `spiffs`, `littlefs`) o incluidos como `const char*` en tu código.
    *   Asegúrate de que los certificados se carguen correctamente al dispositivo.
2.  **Código ESP32 (ejemplo de configuración MQTT):**
    A continuación, se muestra un fragmento de código de ejemplo para configurar la conexión MQTT segura. Necesitarás adaptar esto a tu SDK y bibliotecas específicas (como `esp_mqtt_client`).

    ```c
    #include "esp_mqtt.h"
    // ... otras inclusiones

    extern const uint8_t device_certificate_pem_start[] asm("_binary_device_certificate_pem_start");
    extern const uint8_t device_certificate_pem_end[]   asm("_binary_device_certificate_pem_end");
    extern const uint8_t private_pem_start[] asm("_binary_private_pem_start");
    extern const uint8_t private_pem_end[]   asm("_binary_private_pem_end");
    extern const uint8_t AmazonRootCA1_pem_start[] asm("_binary_AmazonRootCA1_pem_start");
    extern const uint8_t AmazonRootCA1_pem_end[]   asm("_binary_AmazonRootCA1_pem_end");

    void mqtt_app_start(void)
    {
        esp_mqtt_client_config_t mqtt_cfg = {
            .broker.address.uri = "mqtts://YOUR_AWS_IOT_ENDPOINT:8883",
            .credentials.client_id = "esp32_device_01", // Debe coincidir con el ID de cliente en la política
            .credentials.certificate_pem = (const char *)device_certificate_pem_start,
            .credentials.private_key_pem = (const char *)private_pem_start,
            .broker.verification.certificate_pem = (const char *)AmazonRootCA1_pem_start,
            .session.keepalive = 120,
            // ... otras configuraciones
        };

        esp_mqtt_client_handle_t client = esp_mqtt_client_init(&mqtt_cfg);
        esp_mqtt_client_start(client);
    }
    ```
    *   **`YOUR_AWS_IOT_ENDPOINT`:** Este es el endpoint de tu servicio AWS IoT Core. Puedes encontrarlo en la consola de AWS IoT Core, en la sección **Configuración** (Settings), bajo "Punto de enlace de datos del dispositivo" (Device data endpoint). Asegúrate de usar el puerto 8883 para MQTT sobre SSL.
    *   Las líneas `extern const uint8_t ... asm("_binary_...")` son para incrustar los certificados directamente en el binario del ESP32 si utilizas el componente `esp_idf_lib_helpers` o similar para ello. Alternativamente, puedes cargarlos desde el sistema de archivos del dispositivo.

### Paso 5: Probar Conexión y Publicación de Mensajes
Verifica que tu dispositivo se conecta y publica mensajes correctamente.

1.  **Monitor MQTT en AWS IoT Core:**
    *   En la consola de AWS IoT Core, ve a "Probar" (Test) y luego "Cliente de prueba MQTT" (MQTT test client).
    *   En "Suscribirse a un tema", introduce `esp32/data` (o el tema que hayas configurado en tu política y código ESP32) y haz clic en "Suscribirse". Esto te permitirá ver los mensajes publicados por tu dispositivo.
2.  **Flash y ejecutar el firmware en el ESP32:**
    *   Compila y flashea el código de tu ESP32.
    *   Inicia el monitor serie para ver los logs del dispositivo.
3.  **Verificar la comunicación:**
    *   Observa los logs en el monitor serie de tu ESP32 para confirmar que la conexión MQTT se establece correctamente y que se están publicando mensajes.
    *   En el cliente de prueba MQTT de AWS IoT Core, deberías ver los mensajes entrantes de tu dispositivo.

### Consideraciones de Seguridad Adicionales
*   **Políticas con mínimo privilegio:** Siempre diseña tus políticas IoT para otorgar solo los permisos absolutamente necesarios (`least privilege principle`).
*   **Rotación de certificados:** Implementa una estrategia para rotar periódicamente los certificados de tus dispositivos, mejorando la seguridad a largo plazo.
*   **Almacenamiento seguro:** Asegúrate de que las claves privadas del dispositivo estén almacenadas de forma segura y no sean accesibles o extraíbles fácilmente del dispositivo.

### Conclusión
Este proceso proporciona una base sólida para conectar de forma segura dispositivos ESP32 a AWS IoT Core, garantizando una comunicación confiable y protegida. La implementación de certificados y políticas de seguridad es fundamental para mantener la integridad de tu solución IoT.
