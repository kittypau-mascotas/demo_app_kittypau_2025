3.2 FLUJO COMPLETO DE LOGIN (PASO A PASO)
1. Usuario entra a kittypau.app
2. App verifica sesión
3. No hay sesión → /login
4. Usuario ingresa email + password
5. Better Auth → POST /api/auth/signin
6. Neon Auth valida credenciales
7. API setea cookie httpOnly
8. Frontend recibe success
9. Redirect a /dashboard

⚠️ IMPORTANTE

NO JWT en localStorage

NO tokens en JS

Cookies seguras siempre

3.1 Middleware ownership (Drizzle)
export async function assertOwnership({
  userId,
  table,
  resourceId,
}) {
  const result = await db
    .select()
    .from(table)
    .where(and(eq(table.id, resourceId), eq(table.userId, userId)));

  if (!result.length) throw new Forbidden();
}
