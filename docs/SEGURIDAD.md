# Seguridad

## IoT

- Autenticación por certificados X.509
- Policies por deviceId
- Topics MQTT aislados por dispositivo

## Backend

- Autenticación obligatoria
- Middleware de autorización
- Validación de user_id en TODAS las queries

## Principios

- Zero Trust
- Least Privilege
- No acceso directo a DB desde frontend
