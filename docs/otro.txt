🔧 2. Falta una tabla CRÍTICA: device_events

Ahora mismo tienes sensores, pero no tienes historial de estado.

Te recomiendo AGREGAR esto (muy importante para tu app):

CREATE TABLE device_events (
  id SERIAL PRIMARY KEY,
  device_id VARCHAR(50) NOT NULL,
  event_type VARCHAR(50) NOT NULL, -- online, offline, error, reboot
  payload JSONB,
  ts TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_device_events_device_ts
ON device_events(device_id, ts DESC);


Esto te permite:

Mostrar “🟢 Online / 🔴 Offline”

Saber cuándo un dispositivo se cayó

Mostrar timeline del dispositivo

Debug real de IoT (oro puro)
