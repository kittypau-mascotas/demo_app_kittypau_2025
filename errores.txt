✅ OPCIÓN 2: Política básica y segura para MQTT (RECOMENDADA)
👉 Permite conectar, publicar y suscribirse solo a ciertos tópicos.

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "iot:Connect",
      "Resource": "arn:aws:iot:*:*:client/*"
    },
    {
      "Effect": "Allow",
      "Action": [
        "iot:Publish",
        "iot:Receive"
      ],
      "Resource": "arn:aws:iot:*:*:topic/test/*"
    },
    {
      "Effect": "Allow",
      "Action": "iot:Subscribe",
      "Resource": "arn:aws:iot:*:*:topicfilter/test/*"
    }
  ]
}
📌 Esto permite:

Conectarse al broker

Publicar en test/*

Suscribirse a test/*
