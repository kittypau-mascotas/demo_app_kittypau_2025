Ahora mismo tienes:

Esto es correcto si el dispositivo envía timestamp.
Pero en IoT real necesitas doble tiempo:

⏱ ts → tiempo del sensor (origen)

5️⃣ API – respuesta optimizada para frontend

Pequeño upgrade UX.

📌 Mejora en /api/devices

Devuelve ya el último evento:

SELECT
  d.id,
  d.device_id,
  d.name,
  d.status,
  d.last_seen,
  e.ts AS last_event_at
FROM devices d
LEFT JOIN LATERAL (
  SELECT ts
  FROM device_events
  WHERE device_id = d.device_id
  ORDER BY ts DESC
  LIMIT 1
) e ON true
WHERE d.user_id = $1;


👉 Esto evita una llamada extra desde el frontend.
